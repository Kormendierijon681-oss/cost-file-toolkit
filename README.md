# cost-file-toolkit — 造价文件工具箱

两个 ClawHub 技能：把造价软件的"黑盒"工程文件变成可读的 Excel。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
![Platform](https://img.shields.io/badge/platform-macOS%20%7C%20Linux-lightgrey)

| 技能 | 一句话 | 安装 |
|---|---|---|
| **sgcfx-hongye-parse** | 免软件授权，本地解析宏业 `.SGCFX` 计价文件 → 分部分项清单/材料工料机/费用六段式 Excel，支持送审 vs 审核核减对比 | `clawhub install sgcfx-hongye-parse` |
| **cost-file-doctor** | 计价文件诊断器：识别格式、判定加密、给可行路径；附分页重复表头清理器 | `clawhub install cost-file-doctor` |

不装 ClawHub CLI 也可以：把对应目录拷进你的 Agent 技能目录（`~/.workbuddy/skills/`）即可。

---

## 为什么写这个

造价行业的工程文件（清单、材料、费用）全部锁在各家计价软件的私有二进制格式里：
换台电脑打不开、没加密锁打不开、想批量导出 Excel 只能一张张点报表。

本工具箱做了两件事：

1. **证明这类文件并非不可解析**。以宏业 SGCFX 为例：外层是普通 ZIP，内层是明文
   `[长度前缀 UTF-16LE 字符串]` 流，表格结构可以在没有原软件的情况下完整还原。
2. **给出可复用的校验方法论**。二进制逆向最大的风险不是"解不出"而是"解错"，
   所以每个导出环节都强制与文件自身的校验数据互证。

## 实测指标

在一个真实工程文件（3 个单项工程 × 4 个专业 = 12 个单位工程）上验证：

| 校验层 | 内容 | 结果 |
|---|---|---|
| 自校验 | 综合合价 = 综合单价 × 工程量 | 384/384 + 382/382 全过 |
| 分册层 | Σ清单合价 = 文件内部"合计"行 | 12/12，差 ≤ 0.04 元 |
| 链条层 | A+B+C=D、(D−A.1)×9%=E、D−A.1+E=总价 | 12×3 全过 |

## SGCFX 格式速览（详见技能内文档）

```
外层      : ZIP 容器（unzip 即可解开，内部明文）
表头      : 96 字节 —— +4 schema 区长度, +16 表ID
字符串    : [uint32 字符数][UTF-16LE]        ← 数值也常以字符串冗余存储
记录标记  : F段N=分部 / F目N=清单项 / F定N=定额子目
3003 清单 : 序号 → 工程量(字符串!) → F目N → 12位编码 → 名称 → 单位
            → [单价, 合价]（12 字节步长成对）→ 项目特征 → …
3010 汇总 : 六段式 A 分部分项 / B 措施 / C 其他 → D 税前=A+B+C
            → E 增值税=(D−A.1)×9% → F 总价=D−A.1+E
```

三个最容易翻车的坑：

1. **工程量是字符串**（`'73.5'`），不是 double——读 double 会得到垃圾值
2. **ZIP 压缩后熵 ≈ 7.99，与加密文件无法用熵区分**——先解容器再判断
3. 随机字节下"中文串"正则会产生上万假阳性——必须做 CJK 占比二次过滤

## cost-file-doctor 的核心结论

不是所有计价文件都能解析。诊断脚本用三重证据（熵、严格中文串、造价关键词命中）
区分"明文可解析"与"整体加密"。实测：宏业 SGCFX 明文可解；青山水利 `.qhf` 全系
加密（熵 7.99、关键词命中 0），无公开解密方案——**遇到它别逆向，去找同目录
下已导出的 Excel**，通常就在旁边。

## 目录结构

```
sgcfx-hongye-parse/
├── SKILL.md            # 解析方法论 + 踩坑清单
├── scripts/
│   ├── export_boq.py   # 3003 清单 → Excel
│   ├── export_cost.py  # 3010 费用六段式 → Excel
│   ├── p3007.py        # 3007 材料表解析（实测解析率 99.5%）
│   └── ...
cost-file-doctor/
├── SKILL.md
└── scripts/
    ├── diagnose.py     # 格式/加密诊断
    └── tidy_excel.py   # 造价软件导出 Excel 的分页表头清理
```

## 依赖

- Python ≥ 3.9
- `openpyxl`
- （可选）`clawhub` CLI —— 技能市场安装/更新

## 免责与合规

- 本工具箱仅解析**用户自己有权处理**的工程文件，请勿用于未授权数据
- 解析结果为二进制逆向产物，已通过多重勾稽验算，但正式用途请与原软件导出结果抽查比对
- 部分厂商文件为整体加密（文档中已列明），本工具箱不做也不做任何解密
- 文档中的示例数据均已脱敏
